Personal Mail Assistant

Personal Mail Assistant is a small, single-user automation tool for one person's own email account. When the account owner authorizes it, it periodically fetches new incoming messages, classifies each one on the owner's own machine, and organizes the mailbox by applying labels.

Human review first

The tool never sends email by itself and never deletes anything. For messages that look like they deserve a reply, it prepares a draft — the owner reads, edits and sends every reply personally. Label changes are recorded before they are made and can be undone.

Local processing

All classification runs locally on the operator's own hardware. Message content is not shared with, sold to or forwarded to any third party, and it is not used for advertising.

How the tool handles account data is described in the privacy policy.
