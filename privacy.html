Privacy Policy

This policy describes how Personal Mail Assistant handles data when an account owner authorizes it to access their email.

Data accessed

The tool requests access to the authorizing account's email messages and labels (Gmail scope https://www.googleapis.com/auth/gmail.modify). It reads message content and metadata, and it can create, change and remove labels.

How data is used

  • New incoming messages are fetched periodically.
  • Each message is classified on the operator's own machine to decide which labels apply (for example "appointment needed" or "reply suggested").
  • For messages that warrant a reply, a draft reply is prepared. Drafts are never sent automatically — the account owner reviews and sends every reply personally.

Storage and sharing

Classifications and a record of applied labels are stored locally on the operator's own machine. Message content is processed in memory and is not persisted anywhere else. No data is shared with third parties, sold, or used for advertising.

Deletion and reversibility

The tool never deletes email. Label changes are snapshotted before being applied and can be restored. Revoking access in the Google Account security settings stops all processing immediately.

Contact

For questions about this policy, use the user support email address shown on the tool's Google authorization screen.
